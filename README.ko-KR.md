# DMeloper's Block Pet — 테스트 배포

한국어 · [English](README.md)

설치와 업데이트 동작을 확인하기 위한 테스트 배포 저장소입니다. 이곳의 파일은 공식 배포 버전이 아닙니다.

[테스트 빌드 다운로드](https://github.com/oup030416/dmelopers-block-pet-test/releases)

## 설치

`dmelopers-block-pet_*_x64-setup.exe`는 WiX 설치파일입니다. 설치 폴더의 Uninstall 또는 Windows 설치된 앱에서 제거할 수 있습니다. 데이터 삭제는 기본 해제입니다.

Windows 11 24H2 이상(x64)과 Microsoft WebView2 Runtime이 필요합니다. WebView2가 없으면 앱이나 설치 프로그램에서 여는 Microsoft 페이지를 통해 먼저 설치하세요.

앱을 정상 종료한 뒤 EXE 파일을 실행하세요. 설치가 중단되었다면 같은 설치파일을 다시 실행해 프로그램 파일을 복구하세요. 설치 실패 시 MSI 변경은 롤백할 수 있으며, 사용자 데이터의 자동 복원은 제공하지 않습니다.

일반 테스트 빌드는 테스트 전용 서명을 사용하며 공식 설치와 데이터를 따로 보관합니다. 공식 바이너리 검증용으로 표시된 배포본은 해당 바이너리의 공식 업데이트 출처와 Saved Games 공유 데이터를 그대로 사용합니다. 이 저장소에 올렸다고 앱의 동작이 바뀌지는 않습니다.

## 업데이트

현재 1.0.0 설치파일로 설치한 뒤 설정에서 서명된 1.0.1 업데이트를 시험할 수 있습니다. 이전 WiX 이름이 붙은 설치파일은 다운로드 파일명이 다릅니다. 해당 시험본은 데이터 삭제를 해제하고 제거한 뒤 이번 파일로 설치하세요.

테스트 앱은 사용자가 요청하면 더 높은 버전으로 업데이트할 수 있습니다. v1.0.0을 포함한 일반 버전 태그의 테스트 파일은 교체될 수 있습니다. 같은 버전의 교체된 파일을 설치하려면 다시 다운로드해 수동으로 재설치하세요.

공식 바이너리 후보는 별도의 사전 배포 태그를 사용하며 파일을 그대로 보존합니다. 테스트 업데이트 정보나 배지는 갱신하지 않습니다. 설치 전에 각 릴리즈의 설명을 확인하세요.

## 다운로드 경고

다운로드한 파일의 SHA-256을 릴리즈에 표시된 현재 값과 비교하세요. PowerShell에서 `Get-FileHash -Algorithm SHA256 -LiteralPath '<다운로드한 파일>'`을 사용할 수 있습니다. 해시가 같다는 것은 파일 내용이 일치한다는 뜻이며 안전성이나 게시자 신원을 확인하는 것은 아닙니다.

이 GitHub 설치파일에는 Authenticode 서명이 없어 Windows에 알 수 없는 게시자가 표시될 수 있습니다. 함께 제공하는 `.sig` 파일은 별도의 업데이트 서명입니다. 해시가 다르거나 보안 프로그램이 악성코드를 탐지하면 실행하지 마세요.

테스트 결과가 공식 배포 준비나 백신 검사 통과를 뜻하지는 않습니다. 수행하지 않은 검사는 미확인 상태로 남깁니다.

## 저장소 안내

이 저장소에는 테스트 안내와 배지 생성 코드가 있습니다. 배지는 배포 후 갱신하며 정해진 주기로 자동 갱신하지 않습니다. 이전의 변경 불가능한 릴리즈는 기존 저장소에 보존합니다.

[공식 저장소](https://github.com/d-meloper/dmelopers-block-pet)는 별도로 운영하며 공개 전에는 비공개일 수 있습니다. 공식 GitHub판은 사용자가 요청하면 업데이트를 시작하며 Store판은 Windows가 업데이트를 관리합니다.

공식 Minecraft 제품이 아닙니다. Mojang 또는 Microsoft의 승인이나 제휴를 받지 않았습니다.
